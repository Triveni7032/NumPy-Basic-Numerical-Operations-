# Basic Numerical Operations in NumPy

NumPy provides powerful functions for performing numerical and mathematical operations on arrays.

```python
import numpy as np
1. Creating an Array
arr = np.array([10, 20, 30, 40, 50])
2. Addition
print(arr + 5)

Adds 5 to every element.

3. Subtraction
print(arr - 5)

Subtracts 5 from every element.

4. Multiplication
print(arr * 2)

Multiplies every element by 2.

5. Division
print(arr / 2)

Divides every element by 2.

6. Power
print(arr ** 2)

Squares every element.

7. Modulus

The % operator returns the remainder.

print(arr % 3)
8. Sum

np.sum() calculates the total.

print(np.sum(arr))
9. Mean

np.mean() calculates the average.

print(np.mean(arr))
10. Minimum and Maximum
print(np.min(arr))
print(np.max(arr))

min() → Smallest value

max() → Largest value

11. Square Root
print(np.sqrt(arr))

Calculates the square root of each element.

12. Absolute Value

np.abs() converts negative values to positive values.

arr = np.array([-10, -20, 30])

print(np.abs(arr))
13. Rounding
numbers = np.array([10.25, 20.67, 30.45])

print(np.round(numbers))

Rounds values to the nearest integer.

14. Exponential
print(np.exp(arr))

Calculates the exponential value of each element.

15. Logarithm
print(np.log(arr))

Calculates the natural logarithm.

16. Array-to-Array Operations

NumPy can perform calculations between arrays.

a = np.array([10, 20, 30])
b = np.array([1, 2, 3])

print(a + b)
print(a - b)
print(a * b)
print(a / b)
17. Quick Summary
+       → Addition
-       → Subtraction
*       → Multiplication
/       → Division
**      → Power
%       → Modulus

Conclusion

NumPy provides efficient tools for performing numerical, mathematical, and statistical operations on arrays.

These operations are important for Data Analysis, Machine Learning, and Scientific Computing.
